## 哲学体系层次

```
第一层：判断基准
  └─ 作为人，何谓正确？

第二层：人生方程式
  └─ 思维方式 × 热情 × 能力

第三层：日常修炼（六项精进）
  └─ 努力、谦虚、反省、感谢、利他、不烦恼

第四层：经营框架
  ├─ 经营十二条（战略层）
  ├─ 会计七原则（财务层）
  └─ 阿米巴经营（组织层）

第五层：核心概念
  ├─ 动机至善私心了无
  ├─ 水库式经营
  ├─ 大善似无情 / 小善乃大恶
  ├─ 有意注意
  ├─ 把自己逼入绝境
  ├─ 在相扑台中央发力
  └─ 知识→见识→胆识
```
