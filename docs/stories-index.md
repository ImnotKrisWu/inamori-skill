# 稻盛和夫人生故事索引

每个故事对应一种问题类型。当你有相应困惑时，读对应的故事。

---

## 内心不安 → 「心中磁石」故事

**1945年，13岁，患肺结核。**

当时肺结核是不治之症。父亲和哥哥坦然照顾患病的叔父，一点事没有。只有稻盛——每次都捏着鼻子跑过叔父的房间——偏偏被感染了。

躺在病床上，邻居给了一本书《生命的真相》。一句话像闪电击中他：「我们的心中有一块吸引灾难的磁石。我们生病是因为我们有一颗吸引病菌的脆弱的心。」

他瞬间明白了。恐惧本身在召唤灾难。消极的心引来消极的现实。从那一刻起，他只想好事、做好事。后来肺结核不药而愈。

**对你有什么用**：你现在焦虑的事，很可能是你「想」出来的。改变心态，现实就会改变。

## 逆境打击 → 求职绝望故事

**1954年，22岁，大学毕业。**

日本战后经济大萧条。稻盛向无数公司投简历，全部被拒。没有背景、没有名校光环、没有关系——在那个年代，这三样缺一不可。

他绝望到在鹿儿岛的黑社会总堂门口徘徊。心想：反正找不到正经工作，不如去混黑道。

幸好一位教授出手相助，介绍他去京都的松风工业。进去才知道——这是一家快要倒闭的公司。

**对你有什么用**：你以为的绝境，可能是另一条路的起点。没有教授的介绍就没有松风工业。没有松风工业就没有镁橄榄石。没有镁橄榄石就没有京瓷。

## 濒临放弃 → 松风实验室故事

**1955年，23岁，松风工业。**

公司发不出工资，设备破旧不堪，劳资纠纷不断。同期入职的大学生一个接一个辞职。最后只剩稻盛和另外一个人。

他也想走。报考自卫队干部候补生学校。写信回家让家里寄户籍副本。哥哥把信撕了：「哪有人好不容易进了公司，半年不到就辞职的？！」

无路可退。

稻盛做了一个改变一生的决定：把锅碗瓢盆搬进实验室，睡在实验台旁边。没有参考资料，没有先进设备，只有一台旧高温炉和一堆化学试剂。

一年后，他成了日本第一个成功合成镁橄榄石的人。

**对你有什么用**：多数人倒在「不行了」这一刻。撑过去，你就超过了多数人。

## 经营问题 → 员工造反故事

**1961年，29岁，京瓷创业两年。**

一群高中毕业的年轻员工集体要求加薪和奖金保障，威胁罢工。

稻盛花了三天三夜和他们谈判。看着他们的眼睛——不是恶意，是恐惧。怕公司倒闭，怕自己没了饭碗。

他突然意识到：我创立京瓷是为了实现自己的技术梦想。但他们来这里，是为了养家糊口。我完全错了。

1967年正式确立经营理念：「追求全体员工物质与精神两方面幸福的同时，为人类和社会的进步与发展做出贡献。」

**对你有什么用**：经营企业不是为了老板的梦想。企业是为了员工的幸福而存在的。员工不是成本，是目的。

## 道德选择 → KDDI六个月自问

**1984年，52岁。**

稻盛决定进军通信业，挑战垄断企业NTT。所有人都说：做陶瓷的搞什么通信？

他自己也不确定。于是每晚睡前扪心自问：「动机纯粹吗？没有私心吗？不是为了出风头吧？」

自问了整整六个月。一天不落。有时候觉得自己纯粹了，继续追问，又发现了藏在深处的私心。

终于有一天——确认了。是的，没有私心。第二天就动手。

后来KDDI成了世界500强。

**对你有什么用**：只要动机是善的，过程是善的，结果不会差。这是宇宙的法则。不是鸡汤，是拿两家世界500强验证过的。

## 成功自满 → 神的骰子

**2018年，86岁，盛和塾世界大会。**

「神只是随便摇了一下骰子，正好砸中了稻盛和夫。不是我也可以的。在座的哪位代替我，对宇宙来说没有区别。神偶然地将才能寄存在我这里。所以——不能骄傲，不能将才能私有化。」

**对你有什么用**：让你栽跟头的从来不是失败，是成功后的飘飘然。越是顺的时候越危险。

## 领导力 → 拯救日航

**2010年1月19日，日航破产。负债2.3万亿日元。5万人面临失业。**

78岁的稻盛零薪水上任，只坐日航经济舱。

召集50名经营干部，一个月彻底教育。每周四次学习会每次三小时，周六也学。亲自讲六次。课后必交报告，最后集体寄宿集训。

每月业绩报告会持续三天，一百多位高管逐一上台。答不上来当场批评。有人说：「每个月都要经历紧张得直冒汗的三天。」

一年后，日航营业利润2049亿日元，利润率17%，三个世界第一（利润、准点率、服务）。两年七个月重新上市。

**对你有什么用**：最大秘密不是数字。是公司风气变了，员工发自内心与公司同心同德。领导力不是发号施令，是点燃人心。

## 人生意义 → 癌症出家与100元硬币

**1997年，65岁，体检发现胃癌。**

稻盛说：「哦，是癌症啊。那我就不住院了。」当天下午照常去外地演讲。

随后辞去所有职务。把百亿日元股票全部分给员工。走进京都圆福寺剃度出家，法号「大和」。

深秋光脚穿草鞋，挨门挨户托钵化缘。脚趾被沥青路划破渗血。

黄昏回寺路上，一位扫地的老婆婆走过来，从衣袋摸出一枚100日元硬币：「你是修行的出家人吧，肚子一定很饿吧，拿去，买点面包填填肚子。」

当那只苍老的手把硬币塞进稻盛手里的刹那——全身如电击，浑身颤抖，眼泪夺眶而出。

**对你有什么用**：幸福不是拥有多少。幸福是感受到被爱、被关怀的那一刻。而且幸福往往来自你最意想不到的人。

## 关系家庭 → 妻子朝子的故事

**1958年，结婚。婚房十平方米，厕所灶台公用。**

妻子须永朝子原是松风工业同事。稻盛穷得把锅碗瓢盆搬进实验室，她每天偷偷在他桌上放一盒便当。

婚后稻盛一心扑在京瓷。她扛起了全部。三个女儿，没参加过任何运动会、毕业仪式。邻居以为她是寡妇。她多年没买过新衣服。同事发现她还穿着蜜月旅行时的衣服。

有一次稻盛开公司专车回家。她严厉批评：「公车私用，公私必须分清。」

78岁去日航时她身体很不好。跑去求医生：「接下来三年，我可不能倒下。」把他出差的内衣衬衫领带按天数分类打包。

稻盛跟她说：「当所有人都不肯追随我的时候，请你在我身后推我一把。」她回答：「你想让我怎么推都行。」

**对你有什么用**：稻盛这辈子能有今天，至少一半是妻子的功劳。真正的关系不是轰轰烈烈，是六十年的默默陪伴。

## 工作倦怠 → 自燃型的人

**没有具体时间点——这是稻盛一生的姿态。**

世上有三种人：自己就能烧起来的，需要别人点火的，点火也烧不起来的。

稻盛从松风工业实验室找到了乐趣——把一件事做到极致，乐趣就来了。良性循环：喜欢→投入→做出成果→被认可→更喜欢。

多数人刚毕业不知道想干什么。不需要知道。先把手头的事做到极致。做着做着就喜欢上了。

**对你有什么用**：你不是找不到热爱的工作。你是还没把手头的工作做到极致。做到极致的那一天，热爱自然就来了。
